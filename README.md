WasteWise TN - Java Application
📌 Project Description

WasteWise TN is an intelligent waste management platform developed as part of the integrated PIDEV project.
The Java application provides desktop features for managing users, polluted zones, statistics, and smart services related to environmental management.

The objective of the project is to promote environmental awareness and improve waste management processes through modern digital solutions.
